⚠ The Problem: Centralized Warehouses Break at Scale
  • Catastrophic Bottlenecks: Central cloud schedulers become single points of failure when wireless packet loss spikes or latency exceeds 100ms.
  • Aisle Gridlocks & Cascading Deadlocks: Naive stop-and-wait baselines cause robots to freeze in corridors when facing peer conflicts.
  • Rigid Greedy Allocation: Assigning tasks strictly to nearest robots creates extreme spatial congestion hotspots.
  • Zero Fault Resilience: Motor stalls or unexpected corridor obstacles bring the entire central schedule to a halt.
✔ Our Solution: Edge-AI Decentralized Coordination
  • Decentralized P2P Mesh: Robots exchange trajectories and intent via local gossip; decisions are computed onboard in <0.3ms.
  • Priority Inheritance with Backtracking (PIBT): Lower-priority AMRs dynamically yield to urgent missions without central intervention.
  • Hungarian Bipartite Allocation: Polynomial-time Kuhn-Munkres matching factoring distance, dynamic congestion, and battery reserves.
  • Autonomous Deadlock & Fault Recovery: Wait-For Graph (WFG) cycle detection detours blocked robots; peers autonomously reclaim stalled missions.

THEORETICAL FOUNDATIONS & MATHEMATICAL FORMULATIONS

Core Algorithmic Coordination Stack

Our architecture integrates proven mathematical algorithms from multi-agent path finding, combinatorial optimization, and formal verification into a unified, edge-executable coordination stack.

🧮 Hungarian Task Allocation (Kuhn-Munkres)

Solves the maximum bipartite matching problem in polynomial time $O(n^3)$. Constructs a weighted cost matrix $C_{ij}$ between robot $R_i$ and task $T_j$:

C_ij = w_dist · (d_pickup + d_delivery) + w_cong · (Cong_pickup + Cong_delivery) + w_batt · Penalty_batt
Citation: Kuhn, H. W. (1955). The Hungarian Method for the Assignment Problem.
⚡ Priority Inheritance with Backtracking (PIBT)

Decentralized iterative multi-agent path finding. When a higher-priority AMR needs a cell currently targeted by a lower-priority peer, the lower-priority robot temporarily inherits the higher priority and backtracks/yields laterally.

Dynamic Priority: P(R_i, t) = BasePriority(R_i) + WaitSteps(R_i) × 0.2 + Urgency(Task_i)
Citation: Okumura, K., et al. (2022). Priority Inheritance with Backtracking for Iterative MAPF. AIJ.
⏱️ Space-Time A* Search

Expands search nodes in state space $(x, y, t)$ rather than spatial-only $(x, y)$. Validates candidate states against dynamic reservation tables to guarantee that no two robots occupy the same node or swap edges in adjacent time steps.

f(n, t) = g(n, t) + h(n) where (n, t) ∉ ReservationTable
Citation: Silver, D. (2005). Cooperative Pathfinding. AIIDE.
🔄 Wait-For Graph (WFG) Deadlock Detection

Constructs a directed dependency graph $G = (V, E)$ where edge $(R_i \to R_j)$ indicates that $R_i$ is waiting for cell currently occupied or reserved by $R_j$. Detects cycles in $O(V + E)$ using Tarjan's algorithm.

Cycle Break Policy: Robot with Lowest Dynamic Priority performs lateral space-time detour
Citation: Tarjan, R. (1972). Depth-First Search and Linear Graph Algorithms. SIAM.
