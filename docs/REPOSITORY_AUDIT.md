## 2. Inconsistencies & Numerical Reconciliations Identified

### A. Aggregate Benchmark Reduction
- **$26.18\%$** ($8.70\text{s} \to 6.42\text{s}$): Produced in frozen `CHECKPOINT_FINAL_PRE_GAZEBO` (`results/benchmarks/latest_summary.json`) across 200 runs ($10\text{ scenarios} \times 10\text{ seeds}$).
- **$12.06\%$** ($9.21\text{s} \to 8.10\text{s}$): Produced in an earlier un-tuned iteration in commit `25df37f` (`docs/RESULTS.md`).
- **$7.55\%$** ($9.35\text{s} \to 8.65\text{s}$): Produced in an intermediate un-tuned iteration (`docs/ENGINEERING_OPTIMIZATION_REPORT.md`).
- **Resolution**: `results/CANONICAL_SIH_METRICS.json` will be generated directly from the benchmark suite. All documentation, web server endpoints, and reports will strictly derive from this single file.

### B. Test Suite Counts
- **102 / 102 Tests**: Current passing test suite in `tests/` (77 core + 25 ROS 2 adapter tests).
- **77 / 77 Tests**: Stale reference in `web/server.py` and `docs/RESULTS.md` prior to ROS 2 adapter test additions.
- **Resolution**: All references will be synchronized to `102/102 Tests Passing` backed by `results/test_manifest.json`.

### C. Planner Latency
- Mean: $0.27\text{ ms}$, P95: $1.25\text{ ms}$ (from the 200-run comprehensive benchmark).
- Incorrect claim: "sub-millisecond latency" in headline text while reporting P95 of $1.25\text{ ms}$.
- **Resolution**: State exact metrics truthfully: *"Mean planning latency: $0.27\text{ ms}$, P95: $1.25\text{ ms}$ on single-core CPU"*.

### D. Memory Footprint
- **54 MB**: Core Python simulation runtime without Web/GUI dependencies.
- **203.5 MB – 238.7 MB**: Full Digital Twin process including FastAPI, Uvicorn, WebSocket buffers, and telemetry serialization.
- **Resolution**: Clearly distinguish "Core Planner & Coordination Memory ($\approx 54\text{ MB}$)" from "Total Digital Twin Web Server Process ($\approx 238\text{ MB}$)".

### E. 4D vs 3D Space-Time
- Code searches state space $(x, y, t)$ with discrete reservation intervals.
- Calling this "4D Space-Time A*" was inaccurate marketing terminology.
- **Resolution**: Standardize throughout on "Space-Time A* Search over $(x, y, t)$".
